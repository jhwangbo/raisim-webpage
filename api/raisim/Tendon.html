raisim::Tendon ​

class · #include <raisim/constraints/Tendon.hpp>

A scalar transmission: routed spatial length or a weighted sum of scalar joints. Positive tension shortens the tendon; positive actuation force lengthens it. Geometry is massless. Optional armature adds inertia only along tendon length. World owns tendons and removes them when a referenced object is removed.

Nested classes ​

  • struct Drive — Actuator acting along the tendon.
  • struct JointGradient — Length gradient with respect to one joint of a fixed tendon.
  • struct JointTerm — One term of a fixed tendon: length += coefficient * q(joint). Only revolute and prismatic joints are supported.
  • struct PathElement — One element of a spatial tendon route. Create elements with the static factory functions.
  • struct PointGradient — Length gradient with respect to one world-space application point.
  • struct Properties — Passive and limit parameters of a tendon. Forces are in tendon coordinates (N for spatial tendons). Validated by setProperties().
  • struct Site — An attachment point on a body (or in the world frame) used by spatial tendon paths.
  • struct VisualSegment — A straight piece of the routed tendon in world coordinates.
