raisim::HeightMapVisual ​

struct · #include <raisim/server/Visuals.hpp>

Visual-only height map (no physics) streamed by RaisimServer. Create with RaisimServer::addVisualHeightMap(); the server owns it. The constructors forward their arguments to the matching raisim::HeightMap constructor.
