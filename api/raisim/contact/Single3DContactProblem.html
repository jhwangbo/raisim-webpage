raisim::contact::Single3DContactProblem ​

class · #include <raisim/contact/BisectionContactSolver.hpp>

One constraint row (contact, joint limit, wire or pin) of the contact problem that the World solves each step; World::getContactProblem() exposes the list. For contact rows, imp_i is expressed in the contact frame of the corresponding Contact and acts on obA (obB receives the negated impulse).

64-byte aligned so that the hot region below always occupies the same cache lines of every element (with the natural 8-byte alignment, the 16-byte drift of the 848-byte stride made the hot region straddle a different set of lines for each contact)

cpp
Single3DContactProblem() = default

Keep it defaulted: value-initialization (emplace_back()) then zero-fills every member without a default member initializer and makes Mapp_i the active union member. The world refills the same row storage every step, and joint-limit and joint-friction rows set only the fields they use, so a user-provided constructor would hand them the fields of the row stored there before.
