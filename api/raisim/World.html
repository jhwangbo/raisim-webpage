raisim::World ​

class · #include <raisim/World.hpp>

The simulation world. It owns every object, wire and tendon added to it: the raw pointers returned by the add* methods stay valid until the object is removed (removeObject()) or the world is destroyed, and must not be deleted by the caller. Advance the simulation with integrate() (or integrate1() followed by integrate2()). A World is not thread-safe; see lockMutex() for sharing it with another thread (e.g. a visualizer server).

Nested classes ​

  • class Checkpoint — An immutable, reusable in-memory checkpoint of this world's runtime state.
  • struct CollisionCounters — Diagnostic collision counters of the last integration step.
  • struct DepthCameraFrame — Output of captureDepthCamera().
  • struct DepthCameraProperties — Settings of the CPU ray-cast depth camera used by captureDepthCamera().
  • struct ParameterContainer — A template parameter: every @@name token in the template text is replaced by param.
  • struct RayCastBody — Collision geometry of one body, exactly as rayTest() and rayTestLidar() test it.
  • struct SingleBodySnapshot — Snapshot of a single-body object's runtime state and collision properties.
  • struct SleepSettings — Sleeping-island configuration (see setSleepingParameters()).

World ​

cpp
explicit World(uint64_t headerLayoutStamp=detail::headerLayoutStamp())

Create an empty world. The defaulted parameter is an ABI guard: it is evaluated in the caller's translation unit from the headers the application compiled with, and the library compares it with its own value. A mismatch means the application was built against headers whose object layout differs from the loaded libraisim (e.g. stale object files after a reinstall) — a state that otherwise corrupts memory silently. Do not pass this argument manually.

Parameters

ParameterDescription
headerLayoutStamp (in)ABI guard value; leave it defaulted
cpp
explicit World(
    const std::string &configFile,
    const std::vector<ParameterContainer> &params={})

Create a world from a file. The format is chosen from the extension and content: .usd/.usda/.usdc/.usdz (USD articulation, see addUsdArticulatedSystem()), .rscene (RaiSim Engine scene, see getRscene()), otherwise an XML file whose content contains a <mujoco> (MJCF) or <raisim> (RaiSim world config) element. A RaiSim world config can include one .rscene scene with <include value="scene.rscene"/>, e.g. to keep a robot separate from the scene it runs in.

setMonolithicDeformables ​

cpp
void setMonolithicDeformables(bool enabled)

Solve the elastic constraints of deformables inside the contact solve, together with every contact, joint limit and pin (the default), or in the deformables' own substep loops after it. Solved together, the bodies a deformable rests on carry its weight within the step, and a heavy body on a cloth or soft solid rests on whatever supports the particles under it instead of pressing them into it. A deformable with Material::substeps > 1 then makes the whole world step in substeps (integrate() only), in each of which the external forces act with the generalized forces they had when they were set. Takes effect at the next integrate1(). See the Deformable Objects documentation for the cost and the known limitations of both.

Parameters

ParameterDescription
enabled (in)true (default) for the joint solve, false for the deformables after the contact solve
