raisim::Object ​

abstract class · #include <raisim/object/Object.hpp>

Derived by: raisim::ArticulatedSystem, raisim::DeformableObject, raisim::GranularSystem, raisim::SingleBodyObject

Abstract base class of everything that can be added to a raisim::World: single bodies, terrains, articulated systems, deformable objects and granular systems. Objects are created and owned by the World. Functions taking a localIdx address a body (articulated systems) or a particle (deformable/granular); single bodies ignore it (use 0).
