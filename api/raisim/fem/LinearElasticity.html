raisim::fem::LinearElasticity ​

class · #include <raisim/fem/LinearElasticity.hpp>

Small-displacement, small-strain, isotropic, linear static elasticity with four-node tetrahedra. SI units: metres, newtons, pascals, kg/m^3. Instances are single-threaded. Changing loads or prescribed values reuses the factorization; changing the support mask rebuilds it.

setSolverBackend ​

cpp
void setSolverBackend(SolverBackend backend)

Automatic uses CG preconditioned by cached smoothed-aggregation algebraic multigrid for >=5000 free DOFs, sparse LDLT otherwise. Both iterative backends solve to the same relative tolerance. Bolt connectors currently use LDLT.

setProgressCallback ​

cpp
void setProgressCallback(std::function<void(SolveStage stage, double fraction)> callback)

solve() calls this on its own thread with the current stage and the completed fraction of that stage in [0, 1]. Iteration fractions follow the logarithmic residual reduction of the iterative solver. An exception thrown by the callback stops solve() and propagates; the next solve() repeats the interrupted work. Empty disables reporting.
