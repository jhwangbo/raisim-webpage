raisim::Mat ​

class · #include <raisim/math/Matrix.hpp>

Inherits: raisim::MatExpr< Mat< n, m > >

cpp
template <size_t n, size_t m>
class Mat

Fixed-size n x m matrix of doubles, stored column-major: element (i, j) is v[i + j * n]. Vec<n> is the column-vector alias Mat<n, 1>.

The default constructor leaves the elements uninitialized. Arithmetic on Mat objects and other raisim matrix expressions (+, -, *, /, also with scalars) builds expression templates that hold their operands by reference and are evaluated when assigned, so do not store an expression that refers to temporaries (e.g. with auto). Assignment evaluates the expression element by element into the destination: element-wise expressions that read the destination (a = a + b) are fine, but a product or transpose that reads it (a = a * b, a = a.transpose()) gives wrong results; the 4x4 by 4x4 product is evaluated eagerly and is the exception. e() returns an Eigen map of the same memory.

In addition to the members listed here, Mat provides (through a shared macro that is not shown in this reference) norm(), sum(), squaredNorm(), dot() (the operands must have the same number of elements), setZero(), setConstant(), scalar *=, /=, += and -=, element-wise +=, -= and /= with another raisim matrix expression of the same dimensions, assignment from any matrix-like object of the same dimensions, cross() and skew() for 3D vectors, and, for a 1x1 matrix only, an implicit conversion to double. The block, row and column views and the lazy expressions share these members. == and != compare two such expressions of identical dimensions element by element.
