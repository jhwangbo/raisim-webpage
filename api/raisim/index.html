raisim ​

namespace

The RaiSim physics engine: worlds, objects, articulated systems, contacts, sensors and the visualization server.

Classes ​

Core A–P

  • class AlignedAllocator — Standard allocator that returns memory aligned to RSALOCATOR_ALIGNMENT bytes (e.g. for vectors of fixed-size Eigen-backed types).
  • struct CoacdOptions — CoACD convex decomposition parameters for mesh collision approximation.
  • struct ColorRGB — 8-bit RGB color (components 0-255).
  • struct ColorRGBA — 8-bit RGBA color (components 0-255).
  • class DynamicArray — Owning heap buffer of doubles; the common base of VecDyn and MatDyn.
  • struct FluidCoefficients — How a collision shape interacts with fluids. The defaults suit a solid body.
  • struct FluidMedium — A fluid: water, air, oil. A density of zero is no fluid.
  • struct FluidSample — The liquid of a FluidVolume where a body is: its surface over the body and its velocity there.
  • struct FluidVolume — A body of liquid under a free surface: a pool, a lake, the sea.
  • struct FluidWave — A wave on the surface of a deep liquid (linear, Airy): the surface rises by amplitude cos(theta), with theta = k direction .
  • class MatDyn — Dynamically sized matrix of doubles, stored column-major: element (i, j) is v[i + j * rows()].
  • class MaterialManager — Table of contact properties per material pair.
  • struct MaterialPairProperties — Contact properties of a pair of materials.
  • class noiseUtils — Internal: numeric helpers of the terrain noise generator.
  • class Path — A file system path string using the platform separator.
  • class PerlinNoise — 3D Perlin gradient noise with a seeded 256-entry permutation table (period 256 on each axis).

Core R–V

  • class RaiSimMsg — Message printer behind the RSINFO / RSWARN / RSFATAL macros (raisim_message.hpp).
  • class RaisimServer — Streams a raisim::World (plus server-side visual-only objects and charts) over TCP to a visualizer such as the rayrai TCP viewer, and accepts interaction / sim-control requests (pause, step,…
  • class RaiSimTinyXmlWrapper — Read-only convenience wrapper around a TinyXML element, used by the RaiSim XML, URDF and MJCF loaders.
  • class RaiSimTinyXmlWriter — Minimal XML document writer: add top-level elements with operator[] and write the file with saveFile().
  • class RaiSimTinyXmlWriterElement — Builder for one element of an XML document written by RaiSimTinyXmlWriter (used by World::exportToXml()).
  • struct Rasset — A reusable visual asset with collision shapes in the visual's local frame. .rasset files are XML; paths are relative to the descriptor, not the process.
  • class RayCollisionItem — One ray hit returned by World::rayTest().
  • class RayCollisionList — Hit list returned by World::rayTest().
  • class ScopedRaiSimFatalCallback — Restore-on-destruction wrapper for the calling thread's fatal callback.
  • class SparseJacobian — Sparse Jacobian with three rows (e.g. of a point's position or of a body's angular velocity with respect to the generalized velocity) that stores only its non-zero columns.
  • class SparseJacobian1D — Single-row counterpart of SparseJacobian: v holds the non-zero entries as a 1 x size row and entry i is column idx[i] of the full 1 x dof Jacobian.
  • class StopWatch — Wall-clock timer based on std::chrono::steady_clock.
  • class TerrainGenerator — Generates fractal Perlin-noise height samples from TerrainProperties.
  • struct TerrainProperties — Parameters of a fractal Perlin-noise terrain (see TerrainGenerator and World::addHeightMap()).
  • class TimedLoop — Scope guard for fixed-rate loops: its destructor sleeps until loopTimeInUs after its construction.
  • struct Transformation — Rigid transformation stored as a rotation matrix and a translation.
  • class VecDyn — Dynamically sized column vector of doubles (heap storage, see DynamicArray).

Core W

  • class World — The simulation world.

Objects

  • class Box — A rigid box.
  • class Capsule — A rigid capsule (a cylinder capped by two hemispheres) whose axis is the body z axis.
  • class Compound — A rigid body composed of primitive children (BOX, CYLINDER, CAPSULE, SPHERE) with user-given mass properties.
  • class Cone — A cone. Not supported by the current collision engine: the constructor raises a fatal error.
  • class Cylinder — A rigid cylinder whose axis is the body z axis.
  • class Mesh — A rigid body defined by a triangle mesh (create it with World::addMesh()).
  • class Object — Abstract base class of everything that can be added to a raisim::World: single bodies, terrains, articulated systems, deformable objects and granular systems.
  • class SingleBodyObject — Base class of rigid single-body objects (Sphere, Box, Cylinder, Capsule, Mesh, Compound, Ground, ...).
  • class Sphere — A rigid sphere.

Articulated systems

  • struct ActuatorCoupling — A coupling of an actuator's motor to a joint other than the one the actuator drives (see ActuatorDefinition).
  • struct ActuatorDefinition — An actuator: a DC/BLDC motor with its gear.
  • struct ActuatorState — The state of an actuator in the last simulation step, with the motor quantities on the motor (rotor) side of its gear.
  • class ArticulatedSystem — A tree of rigid bodies connected by joints (robot), simulated in generalized coordinates.
  • class ArticulatedSystemOption — Options passed to the ArticulatedSystem constructors.
  • class Body — Inertial, collision and visual properties of a link, used to build an articulated system (see Child).
  • class Child — Node of a kinematic tree (a body plus the joint connecting it to its parent), used to build an ArticulatedSystem programmatically.
  • struct CollisionBody — Collision geometry description of a Body, used when building an articulated system (see Body::addCollisionObject()).
  • struct CollisionDefinition — collision definition that is stored in Articulated System (see ArticulatedSystem::getCollisionBodies()).
  • class CoordinateFrame — A coordinate frame of an articulated system, defined at every joint (including fixed joints) and at sensors.
  • struct DcMotorParameters — Steady-state electrical model of the DC/BLDC motor inside an actuator, on the motor (rotor) side of the actuator's gear, in SI units.
  • class Joint — Joint connecting a body to its parent; used to build an articulated system (see Child).
  • struct MotorTorqueBounds — admissible motor torque interval at a given motor speed
  • struct Track — A rigid track (continuous belt) of an articulated system, defined by a URDF <track> element.
  • struct TrackDefinition — Internal: a <track> as read by the URDF loader, with its belt geometry already added to the link.
  • struct TrackDrive — A joint that moves the belt of a track: it adds gain * (joint velocity) to the belt speed.
  • struct VisObject — visualization definition created by a user or URDF

Terrain

  • class DeformableTerrain — A triangulated soil surface with no particles or soil inertia.
  • class Ground — A static infinite ground plane (half-space) with normal +z. Create it with World::addGround().
  • class HeightMap — A static terrain defined by a regular grid of heights (create it with World::addHeightMap()).

Deformable objects

  • class DeformableObject — A position-based (XPBD/PBD) deformable body made of particles connected by distance constraints (mesh edges plus optional extra edges) and, for cloth, bending constraints between adjacent triangles.

Granular media

  • class GranularPoolSleepController — Opt-in approximation for a settled pool.
  • class GranularSystem — A discrete-element (DEM) system of spherical particles stepped as one object (create it with World::addGranularParticles() or World::addGranularBox()).

Constraints and tendons

  • class CompliantLengthConstraint — A length constraint that acts as a linear spring (created by World::addCompliantWire()).
  • class Constraints — Base class of world-level constraints (see LengthConstraint). Holds the name, visualization color and a mutex.
  • class CustomLengthConstraint — A length constraint that applies a user-specified tension (see setTension(); created by World::addCustomWire()).
  • struct EqualityConstraintDefinition — Description of an equality constraint inside an articulated system, as parsed from URDF.
  • class LengthConstraint — Base class of the legacy distance constraints ("wires") between two points on two objects.
  • struct MimicConstraint — Internal: a resolved mimic constraint between two one-degree-of-freedom joints.
  • struct MimicConstraintDefinition — Description of a mimic constraint, as parsed from URDF (<mimic>) or MJCF (<equality><joint>): the follower joint's position is kept at multiplier * (leader position) + offset.
  • class PinConstraint — Internal: a resolved point constraint between two bodies of one articulated system.
  • struct PinConstraintDefinition — Description of a pin (point-to-point) constraint inside an articulated system, as parsed from URDF/MJCF.
  • class StiffLengthConstraint — A length constraint enforced as a hard limit (created by World::addStiffWire()).
  • class Tendon — A scalar transmission: routed spatial length or a weighted sum of scalar joints.
  • class TendonCoupling — Constrains the length of one tendon to a polynomial of another tendon's length.

Contact and collision

  • struct CollisionBodyFluid — Internal: how fluids act on a collision body, and the fluid view of its shape, built when a fluid first reaches it.
  • class CollisionBodyFluidSlot — Internal: the CollisionBodyFluid of a collision body, copied with it, in one pointer that stays empty for bodies no fluid has reached.
  • struct CollisionBodyHandle — Internal: per-body collision data registered with the contact engine (shape, owner, material).
  • class Contact — A contact point between two collision bodies, as stored in Object::getContacts().

Sensors

  • struct CameraFisheyeDistortion — OpenCV-fisheye (Kannala-Brandt) distortion coefficients k1..k4.
  • struct CameraIntrinsics — Pinhole-style camera intrinsics in pixels.
  • struct CameraLensModel — Lens description of a camera sensor: projection model, intrinsics and fisheye distortion.
  • class DepthCamera — Depth camera simulated by CPU ray casting against the collision geometry of the world.
  • class InertialMeasurementUnit — An ideal or stochastic six-axis IMU.
  • class RGBCamera — Color camera sensor.
  • class Sensor — Base class of all sensors attached to an ArticulatedSystem frame (RGBCamera, DepthCamera, InertialMeasurementUnit, SpinningLidar).
  • class SensorSet — A named group of sensors that belongs to one body of an ArticulatedSystem (e.g., all sensors of one physical device).
  • class SpinningLidar — Spinning (rotating-head) lidar simulated by CPU ray casting.

Server and visuals

  • struct ArticulatedSystemVisual — Visual-only articulated system (no physics) streamed by RaisimServer.
  • class BarChart — Bar chart (histogram) with one bar per named category.
  • class Chart — Base class of the charts streamed by RaisimServer (TimeSeriesGraph, BarChart).
  • struct HeightMapVisual — Visual-only height map (no physics) streamed by RaisimServer.
  • struct InstancedVisuals — Many visual-only instances of one shape, drawn with per-instance pose, scale and a color interpolated between color1 and color2.
  • struct PointCloud — Point cloud streamed by RaisimServer.
  • struct PolyLine — Visual-only polyline streamed by RaisimServer.
  • class TimeSeriesGraph — Line chart of one or more named series over time.
  • struct VisualMesh — Visual mesh created by RaisimServer::addVisualMesh(), either from a file or from raw arrays.
  • struct Visuals — Visual-only primitive (sphere, box, cylinder, capsule, arrow or mesh) streamed by RaisimServer.

Math

  • class BlockRef — Fixed-size n x m block view of a matrix, returned by Mat::segment(), Mat::head(), Mat::tail(), Mat::block() and the corner accessors.
  • class ColRef — View of one column (n elements) of a matrix, returned by Mat::col().
  • class CrossProduct — Lazy 3D cross product u x v of two 3x1 expressions, returned by cross() on a 3D vector.
  • class DiagonalRef — Placeholder proxy for a matrix diagonal. It has no accessors and no Mat method returns it.
  • class Div_SL_op — Lazy scalar / matrix element-wise expression (Div_SL_op), returned by operator/(double, MatExpr).
  • class ElementRef — Proxy returned by the comma initializers (Mat::operator<<() and DynamicArray::operator=(double)); each following , value writes the next element in linear (column-major) order.
  • class Mat — Fixed-size n x m matrix of doubles, stored column-major: element (i, j) is v[i + j * n].
  • class MatExpr — CRTP base of all fixed-size matrix types and expression templates (Mat, the block views and the lazy arithmetic expressions).
  • class Prod_op — Lazy matrix-product expression returned by operator* on two fixed-size matrix expressions.
  • class Prod_op< Mat< 4, 4 >, Mat< 4, 4 > > — Specialization for the 4x4 by 4x4 product: it is evaluated eagerly (with Eigen) when constructed and stores the result.
  • class RowRef — View of one row (m elements) of a matrix, returned by Mat::row().
  • class SkewRef — Proxy returned by skew() on a 3D vector.
  • class Sub_SL_op — Lazy scalar - matrix expression (Sub_SL_op), returned by operator-(double, MatExpr).
  • class Transpose — Lazy expression for the transpose of a fixed-size matrix expression, returned by Mat::transpose().

cpp
MotorTorqueBounds motorTorqueBounds(
    const DcMotorParameters &motor,
    double speed)

Admissible motor torque at motor speed speed [rad/s]. Above the speed at which even full reverse voltage cannot keep the current below the peak, the voltage band no longer reaches the peak-torque band: every admissible voltage drives more than the peak current against the back EMF. The saturated core caps the torque at the peak torque, so the interval collapses to the peak torque that opposes the motion (-peak above the forward overspeed, +peak below the reverse one).
