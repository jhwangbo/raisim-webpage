raisim::LengthConstraint ​

abstract class · #include <raisim/constraints/LengthConstraint.hpp>

Inherits: raisim::Constraints
Derived by: raisim::CompliantLengthConstraint, raisim::CustomLengthConstraint, raisim::StiffLengthConstraint

Base class of the legacy distance constraints ("wires") between two points on two objects. Create them with World::addStiffWire(), World::addCompliantWire() or World::addCustomWire(); the world owns them. Internally each wire is backed by a two-site spatial Tendon.

StretchType ​

cpp
enum class StretchType : int

Which length deviation the wire resists.

EnumeratorValueDescription
STRETCH_RESISTANT_ONLY0Resists only distances longer than the length (like a rope). Default for stiff and compliant wires created by World.
COMPRESSION_RESISTANT_ONLYResists only distances shorter than the length.
BOTHResists both.
