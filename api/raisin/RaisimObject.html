raisin::RaisimObject ​

class · #include <rayrai/RaisimObject.hpp>

Render state of one raisim::Object, built from physics snapshots.

RaisimObject owns the meshes, colors and world transforms of an object as of the last applied PhysicsObjectSnapshot. It never reads the source raisim::Object, so it stays usable after the object is removed; the snapshot's object pointer is an identity key only.

RaisimObject ​

cpp
RaisimObject(
    const PhysicsObjectSnapshot &snapshot,
    RayraiWindow *parent,
    std::shared_ptr<RayraiGlobalAsset> asset)

Build the render state of a snapshot object.

Builds or fetches the geometry of every visual (articulated systems get both visual and collision meshes). Primitive and file meshes come from asset and are shared with other objects; meshes of hidden capsules and mesh files load once the object is shown. Requires a current GL context.

Parameters

ParameterDescription
snapshotObject state, copied; it must have a description.
parentOwning RayraiWindow (for shared textures and settings).
assetAsset cache to load primitive/mesh geometry.

apply ​

cpp
Changes apply(const PhysicsObjectSnapshot &snapshot)

Advance to a newer snapshot of the same object.

Uploads changed mesh vertices (a vertex delta when the snapshot provides one) and rebuilds meshes whose shapes changed. An unchanged revision costs a comparison. Requires a current GL context.

Parameters

ParameterDescription
snapshotObject state with the same object identity, copied when it changed.

Returns What changed.

configureGroundMaterial ​

cpp
void configureGroundMaterial(
    bool reflective,
    float roughness,
    float metallic,
    bool proceduralChecker=false)

Configure ground and heightmap terrain materials. No-op for other objects.

For a ground plane, resets its material and makes it PBR with planar reflection when reflective, or simple/textured otherwise. For a heightmap, only the window's terrain overrides are reapplied and the other arguments are ignored.

Parameters

ParameterDescription
reflectiveUse a reflective PBR ground.
roughnessPBR roughness, clamped to [0.04, 1] (reflective only).
metallicPBR metallic factor, clamped to [0, 1] (reflective only).
proceduralCheckerDraw a procedural checker instead of the ground texture.
