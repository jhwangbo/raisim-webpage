raisin::Light ​

class · #include <rayrai/Light.hpp>

Simple light with optional shadow map support.

Supports all LightType models and owns the shadow-map framebuffer and depth textures used by the renderer. GL resources are created lazily by the shadow pre-pass methods (which need a current OpenGL context) and released in the destructor when the creating context is current; otherwise the ids are dropped without deletion. Non-copyable and non-movable.

setSpotAngles ​

cpp
void setSpotAngles(float innerDeg, float outerDeg)

Set the spotlight cone half-angles in degrees.

Convenience wrapper around the raw cosine fields. The inner cone is the fully-lit region; intensity falls off smoothly between innerDeg and outerDeg. Pass any values; they are clamped so that innerDeg <= outerDeg.

Parameters

ParameterDescription
innerDegHalf-angle in degrees where falloff begins.
outerDegHalf-angle in degrees where light reaches zero.

setRange ​

cpp
void setRange(float rangeMeters)

Set the attenuation of a point, spot or area light from its range in metres.

Sets the inverse-quadratic coefficients 1, 4.5/range and 75/range^2: full intensity at the source, about 1% (1/80.5) at the range, and still decreasing beyond it (it never reaches zero, and the range does not limit which objects the light shades). Use this instead of writing constant/linear/quadratic by hand. radius, the source size, is not changed.

Parameters

ParameterDescription
rangeMetersDistance at which the light contribution falls to about 1%.

shadowPrePass ​

cpp
bool shadowPrePass()

Prepare for 2D shadow depth rendering.

Ensures the framebuffer, updates lightSpaceMatrix_, binds the FBO, sets the viewport, clears depth, enables polygon offset and disables face culling (restored by shadowPostPass()). Requires a current GL context.

Returns Always true; failures throw as in ensureShadowFramebuffer().

shadowPrePassInto ​

cpp
bool shadowPrePassInto(unsigned int framebuffer, bool clearDepth)

Prepare 2D shadow depth rendering into another framebuffer.

Same as shadowPrePass() but binds framebuffer, whose depth attachment must match the allocated shadow map size, and clears depth only when clearDepth is set. Call ensureShadowFramebuffer() first.

Parameters

ParameterDescription
framebufferFramebuffer to render into.
clearDepthClear the depth attachment before rendering.

Returns Always true.

updateShadowMatrix ​

cpp
void updateShadowMatrix(int snapResolution)

Recompute lightSpaceMatrix_ (used by standalone shadow maps and atlas tiles).

Directional lights use an orthographic box (see setShadowOrtho()) around the shadow center; spot lights a perspective frustum fitted to the outer cone; area lights a 150 degree frustum; point lights a 90 degree frustum.

Parameters

ParameterDescription
snapResolutionShadow-map resolution in texels used to snap directional shadows to the texel grid (reduces shimmering).

Attenuation

Inverse-quadratic falloff for point, spot and area lights: intensity / (constant + linear*r + quadratic*r^2) where r is in metres (never less than radius). Ignored for directional lights. Use setRange() for a more ergonomic alternative.
