raisin::tcp_viewer::SceneSync ​

class · #include <rayrai/TcpSceneSync.hpp>

Finds, downloads and loads the server's scene for one viewer connection.

Drive it from the viewer loop: appendRequests() before each update request, receive() with each response, poll() once per frame. File checks and scene loading run on a worker thread; everything else runs on the caller's thread.

setServerPathsTrusted ​

cpp
void setServerPathsTrusted(bool trusted)

Whether the files may be looked for at the server's own paths before the user agrees.

Set it for a server on this computer, whose paths name this computer's files: its scene then loads in place without a prompt. Files that are not found there still wait for acceptDownload(), so a remote server behind a local port (an SSH tunnel) is still asked for. Without it, the server's paths are read only after acceptDownload(), and the files found there are copied into the scene directory like downloaded ones, so later connections find them without asking. Takes effect at the next file check; reset() keeps it.
