Classes ​

  • struct BodyFramePose — One body frame in world coordinates, independent of its visual geometry offsets.
  • struct BufferReader — Lightweight reader for binary message buffers.
  • struct BufferWriter — Lightweight writer for binary message buffers.
  • struct ClientRequest — A single pending client request to be flushed on the next update.
  • struct ContactSample — Contact sample for contact visualization.
  • struct DeformableMesh — Dynamic triangle mesh data for a deformable object.
  • struct HeightmapMeshData — CPU geometry produced for a heightmap received by the TCP viewer.
  • struct HeightmapPlane — Heightmap plane data for mesh updates.
  • struct InstancedEntry — State associated with a remote instanced visual set.
  • struct ObjectListItem — Entry for selectable object list UI.
  • struct PendingSensorUpdate — Pending sensor update to be applied on the viewer side.
  • struct RemotePointCloud — State associated with a remote point cloud.
  • class RemoteScene — Client-side representation of a remote raisim scene.
  • struct RemoteSceneState — Persistent client-side state mirrored from the remote server.
  • struct SceneFileBlock — The scene-file block of one server response.
  • struct SceneFileEntry — One file of the server's scene.
  • class SceneSync — Finds, downloads and loads the server's scene for one viewer connection.
  • struct SelectedActuatorInfo — An actuator (a motor with its gear) of a selected articulated system: what defines its motor's operating region (raisim::ActuatorDefinition) and its state over the last simulation step…
  • struct SelectedObjectInfo — Details about a selected object from the remote scene.
  • struct SensorInfo — Metadata for a remote sensor.
  • struct ServerControl — A slider of the server (raisim::RaisimServer::addSlider(), ViewerCommandType::SetControls).
  • struct StreamedFluidVolume — A volume of liquid of the server (ViewerCommandType::SetFluidVolumes).
  • class TcpClient — Cross-platform TCP client for the Rayrai/RaisimServer protocol.
  • struct TcpMeshBatch — Instanced mesh batch synthesized from repeated TCP visual entries.
  • struct ViewerCommand — A server-originated command that must be completed by the viewer application.
  • struct VisualEntry — State associated with a remote visual object.
  • struct VisualEntrySnapshot — Copy of a VisualEntry together with its object tag and body index.

sendSensorUpdate ​

#include <rayrai/RaisimTcpCommon.hpp>

cpp
bool sendSensorUpdate(
    TcpClient &client,
    const std::vector<PendingSensorUpdate> &pending,
    size_t &nextSensorIndex)

Send a batch of pending sensor updates.

Sends as many entries as fit in RaisimServer's 32 MiB receive buffer. When not all fit, successive calls rotate the starting entry so every sensor is eventually sent.

Parameters

ParameterDescription
clientTCP client instance.
pendingPending sensor updates to send.
nextSensorIndexRotation state of this sender: the entry the batch starts from (modulo pending.size()). Advanced past the last entry sent. Keep one per connection, starting at 0.

Returns True on successful send.

buildHeightmapMeshData ​

#include <rayrai/TcpHeightmapMesh.hpp>

cpp
bool buildHeightmapMeshData(
    const HeightmapPlane &heightmap,
    HeightmapMeshData &meshData,
    bool worldTiledUv=false)

Build the CPU-side render mesh for a remote heightmap.

Triangles containing NaN or infinite heights are omitted. Such heightmaps retain their source grid so every remaining source triangle is drawn. Resamples the heights onto the visual grid with the physics triangulation and computes normals and tangents. Texture coordinates span the heightmap once, for its streamed color map, or with worldTiledUv tile every 4 m of world XY like world heightmaps, for the renderer's heightmap terrain textures (RayraiWindow::applyHeightmapTerrainTextures()).

Parameters

ParameterDescription
heightmapReceived heightmap.
meshDataOutput; reset on entry.
worldTiledUvTile the texture coordinates in world space.

Returns False if the heightmap has fewer than 2 samples per axis or a height-count mismatch.

kDefaultPort ​

#include <rayrai/TcpProtocolReader.hpp>

cpp
constexpr int kDefaultPort

Default TCP port for the viewer protocol.

The current wire format is a native-endian binary protocol shared by RaisimServer and this viewer. Each TCP frame starts with an int32_t total frame size, including the 4-byte header. Strings in both directions (including sensor names in REQUEST_SENSOR_UPDATE) use int32_t byte-length prefixes.

kProtocolFeatureSimControl ​

#include <rayrai/TcpProtocolReader.hpp>

cpp
constexpr uint64_t kProtocolFeatureSimControl

Negotiates interactive sim control. When both sides advertise this bit, the client may send CR_PAUSE / CR_RESUME / CR_STEP_N / CR_APPLY_FORCE / CR_APPLY_TORQUE / CR_SET_POSE / CR_SET_GC. There is no authentication – the bind address is the only access control (bind to loopback unless you trust the network).
