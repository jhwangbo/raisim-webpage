raisin::tcp_viewer::RemoteScene ​

class · #include <rayrai/RaisimTcpCommon.hpp>

Client-side representation of a remote raisim scene.

Owns the state updated through TCP messages and exposes helper queries for selection, bounds, and visual lists.
