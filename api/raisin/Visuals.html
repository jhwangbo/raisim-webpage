raisin::Visuals ​

class · #include <rayrai/Visuals.hpp>

Renderable visual object not owned by raisim::World.

Visuals encapsulate geometry, transform, and appearance for custom renderable shapes or meshes.

The world transform is position, then orientation, then a per-axis scale applied in the mesh's local frame (Z-up world, quaternions passed as wxyz). Built-in primitives and file meshes come from RayraiGlobalAsset and are shared with other visuals; per-visual appearance belongs in the color, material override/remap/overlay and flags below rather than in the shared meshes. Setters only change state (and renderRevision()); GL work happens when the renderer draws, so drawing requires a current GL context.

Nested classes ​

  • struct FrameCacheMaterialState — Summarize static frame-cache material state in one mesh traversal.
  • class FrameCacheMaterialStateMemo — Internal: memo keyed by mesh list, letting visuals that share meshes reuse frameCacheMaterialState() results.
  • struct MaterialSortKeys — Internal: materialSortKey() for the three common render modes.

cpp
void setPbrEnvironment(
    unsigned int environmentMap,
    unsigned int brdfLut=0,
    float strength=1.0f)

Apply an image-based lighting environment to all PBR submeshes.

Parameters

ParameterDescription
environmentMapGL cubemap id (0 clears).
brdfLutSplit-sum BRDF LUT texture id, or 0.

cpp
void setPbrEnvironment(
    unsigned int environmentMap,
    unsigned int irradianceMap,
    unsigned int prefilteredEnvironmentMap,
    unsigned int brdfLut,
    float strength=1.0f,
    bool boxProjection=false,
    const glm::vec3 &probePosition=glm::vec3(0.0f),
    const glm::vec3 &boxMin=glm::vec3(0.0f),
    const glm::vec3 &boxMax=glm::vec3(0.0f))

Apply split image-based lighting maps to all PBR submeshes.

This mirrors the real-time IBL layout used by engines such as Filament: a display/environment cubemap, diffuse irradiance, prefiltered specular radiance, and a split-sum BRDF LUT. Supplying the full set gives whole-scene imported visuals the same high-fidelity path used by hand-built PBR meshes.

The ids are written into the materials of this visual's meshes (and LOD meshes), material override, remaps and overlay, skipping materials that look like plain simple-shaded ones; a non-zero cubemap also switches those materials to Type::PBR. Mesh materials are edited in place, so other visuals sharing the same cached meshes see the change. Texture ids are not owned.

Parameters

ParameterDescription
environmentMapRadiance/display cubemap id.
irradianceMapDiffuse irradiance cubemap id, or 0.
prefilteredEnvironmentMapPrefiltered specular cubemap id, or 0.
brdfLutSplit-sum BRDF LUT texture id, or 0.
strengthEnvironment strength (capped further for heightmap terrain).
boxProjectionEnable box-projected (parallax-corrected) reflections.
probePositionProbe capture position in world coordinates.
boxMinWorld-space minimum corner of the projection box.
boxMaxWorld-space maximum corner of the projection box.

setMaterialOverride ​

cpp
void setMaterialOverride(std::shared_ptr<Material> material)

Override the visual's draw material with a shared instance.

Ownership. The same shared_ptr<Material> may be held by any number of other visuals — setMaterialOverride does not deep-copy. Mutating the pointed-to material from any holder is observed by every visual that shares it. If you want an in-place edit that affects only this visual, call the const Material& overload (which copies into a new shared instance) or grab a fresh copy via *materialOverride() and push it back through setMaterialOverride(Material{...}).

The override replaces the material of every submesh (and takes precedence over material remaps); the meshes' own OpenGLMesh::textures are then ignored.

Parameters

ParameterDescription
materialMaterial to draw with; null clears the override.
