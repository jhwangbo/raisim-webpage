raisin::FoliageMeshLodBaker ​

class · #include <rayrai/FoliageMeshLodBaker.hpp>

A textured 3D foliage LOD reconstructed from six or ten source-mesh captures. Each small surface patch stays fixed in world axes; it never faces the view. Source leaf holes, albedo and normals survive in the atlases. Call update() until zero before using tile().levels. This baker owns textures and must outlive every visual using them; use on the current GL render thread. Self-shadow visibility is baked for the example's fixed sun; runtime PBR lights the mesh. This is not Nanite or a foliage voxel ray tracer.

  • struct Geometry — CPU triangle mesh.
  • struct Tile — One baked cell: its source placements and the resulting LOD meshes and atlases.

void setPreparedCache(

    uint64_t contentKey)

Enable an on-disk cache of baked tiles in directory, keyed partly by contentKey. The caller's content key must cover source meshes, material settings, textures and baker implementation changes. Capture layout, roots, tint and lighting are additionally fingerprinted here. Configure before update().

install ​

cpp
void install(InstancedVisuals &visual, size_t index) const

Install this tile's three resolutions in the renderer's six selection slots. Grid spacing is an approximation budget, not a Hausdorff bound. Verify silhouettes from oblique views before choosing production grids. Uses an error budget of 0.5 / grid for each level.
