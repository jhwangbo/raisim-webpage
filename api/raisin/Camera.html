raisin::Camera ​

class · #include <rayrai/Camera.hpp>

Camera for offscreen rendering and interaction.

The camera owns its render targets (scene color/depth, post-process, linear depth, and picking). It can be driven by user input or by raisim sensor parameters.

Move forward/backward or zoom in orthographic mode.

Free perspective camera: moves steps metres along front. Orthographic: scales orthoScale by 0.9^steps (min 0.1), so positive zooms in. Orbiting a target or with a fixed distance: scales the orbit distance by 1.2^steps (min 0.05 m), so positive steps move away from the target.

updateAutoExposure ​

cpp
void updateAutoExposure(
    float targetKey,
    float speed,
    float minFactor,
    float maxFactor)

Sample mean scene-color luma and lerp the auto-exposure factor.

Every 4th call issues an asynchronous PBO readback of the smallest mip of the post-process (or scene) color; a completed earlier readback, if any, yields the mean luma, and autoExposureFactor_ is smoothed toward targetKey / mean. Never blocks: without a ready sample the factor is unchanged. Should be called once per frame, after post-process completes. The stored factor is then applied to the next frame's pbrExposure.

Parameters

ParameterDescription
targetKeyDesired mean luma (approximately linear, 0..1).
speedLerp factor per update, clamped to [0, 1].
minFactorLower clamp of the exposure factor.
maxFactorUpper clamp of the exposure factor.

getRawImage ​

cpp
void getRawImage(
    raisim::RGBCamera &sensor,
    SensorStorageMode mode=SensorStorageMode::SENSOR_SETTER,
    char *customBuffer=nullptr,
    size_t customBufferSize=0,
    bool flipVertical=true) const

Read the color buffer into a raisim RGB camera or custom buffer.

Synchronously reads the scene color target (before post-processing) as 8-bit BGRA, width*height*4 bytes; each channel is clamped to [0, 1] and rounded to the nearest 8-bit value. Hardware renderers pack the image on the GPU; software renderers convert native half-float pixels with exact CPU arithmetic. The sensor resolution must match the render target and the scene color target must exist (fatal otherwise). Requires a current GL context. The sensor's configured measurement noise is applied in place after readback, in either storage mode; each call advances that sensor's random stream.

Parameters

ParameterDescription
sensorRaisim RGB camera providing the resolution; filled when using SENSOR_SETTER.
modeStorage mode (sensor setter or custom buffer).
customBufferDestination for BGRA bytes when using CUSTOM_BUFFER (required then).
customBufferSizeSize of custom buffer in bytes (at least width*height*4).
flipVerticalWhether to flip rows from GL origin to image origin.

    raisim::DepthCamera &sensor,
    SensorStorageMode mode=SensorStorageMode::SENSOR_SETTER,
    float *customBuffer=nullptr,
    size_t customBufferLength=0,

Read the linear depth buffer into a raisim depth camera or custom buffer.

Synchronous read of the R32F linear-depth target. With flipVertical the rows are reversed on the GPU for hardware renderers or in CPU memory for software renderers, preserving sample bytes. The sensor resolution must match the render target and the linear-depth target must exist (fatal otherwise). The sensor's configured measurement noise, quantization and dropout are applied in place in either storage mode. Readback does not populate the sensor's 3D points.

glm::vec3 position

Camera pose and view parameters (public for quick access).

Distances are in world units (typically metres). Angles in degrees unless the field name ends in Rad. nearPlane/farPlane and zNear/zFar are overlapping pairs from earlier API revisions: they are not aliases; the projection uses the wider of the two ranges (see getProjectionClipRange()), so with the default zNear of 0.01 raising only nearPlane has no effect. Prefer nearPlane/farPlane in new code.

position, front, up, right are world-space; front/up/right are recomputed by update(). target is the orbit point used only while setCameraFixedTarget(true) is active. worldUp is the up reference.
