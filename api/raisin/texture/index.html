raisin::texture ​

namespace

Free-function texture creators decoupled from RayraiWindow.

The same loaders are also reachable as static methods on RayraiWindow for historical reasons (RayraiWindow::loadHdrEquirectangularCubemap, etc.). Prefer the raisin::texture:: form in new code — it makes clear that the call is a stateless GL utility, not a scene-mutating operation, and keeps RayraiWindow's instance-method autocomplete uncluttered.

All functions require a current OpenGL context.

Functions ​

loadTextureWithTiling ​

#include <rayrai/Texture.hpp>

cpp
unsigned int loadTextureWithTiling(
    const char *path,
    bool useSrgbFormat=false)

Load an image file into an OpenGL texture with repeat tiling.

Parameters

ParameterDescription
pathPath to an image file supported by stb_image.
useSrgbFormatIf true, RGB/RGBA textures are uploaded as sRGB color textures. Use true for albedo/emissive color maps and false for data maps such as normal, metallic-roughness, AO, depth, and masks.

Returns OpenGL texture id, or 0 on failure.

The texture gets GL_REPEAT wrapping, mipmaps, and the process-wide defaults from setDefaultTextureFilteringQuality(). Results are cached per thread and per GL context by (path, sRGB flag), so repeated calls return the same id; a failed load is cached as 0 too. Requires a current GL context.

updateSingleChannelTexture ​

#include <rayrai/Texture.hpp>

cpp
unsigned int updateSingleChannelTexture(
    unsigned int existingTextureId,
    int width,
    int height,
    const unsigned char *data)

Create or update a single-channel R8 2D texture from raw pixel data.

Used for terrain splat control maps. Pass existingTextureId 0 to allocate a new texture, otherwise the existing texture is updated in place (and reallocated if the dimensions differ). New textures use linear filtering and clamp-to-edge wrapping. Requires a current GL context.

Parameters

ParameterDescription
existingTextureIdTexture to update, or 0 (or a deleted id) to create one.
widthWidth in pixels; must be positive.
heightHeight in pixels; must be positive.
datawidth * height tightly packed bytes; must not be null.

Returns The texture id (new or reused), or 0 on invalid input.

setTextureFilteringQuality ​

#include <rayrai/Texture.hpp>

cpp
void setTextureFilteringQuality(
    unsigned int target,
    unsigned int textureId,
    float anisotropy,
    float mipLodBias)

Apply minification quality controls to an existing texture.

Positive mip LOD bias prefers blurrier mips and reduces distant texture shimmer. Negative values sharpen but can alias, so RayRai clamps the bias to [-1, 2].

Parameters

ParameterDescription
targetTexture target such as GL_TEXTURE_2D.
textureIdOpenGL texture id; 0 is ignored.
anisotropyRequested anisotropy, see setTextureAnisotropy().
mipLodBiasMip LOD bias, clamped to [-1, 2].
