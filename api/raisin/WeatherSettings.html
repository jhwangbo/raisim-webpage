raisin::WeatherSettings ​

struct · #include <rayrai/Weather.hpp>

Weather state applied on top of the renderer (RayraiWindow::setWeatherSettings()).

While enabled is true the window re-derives its effective RenderQualitySettings from the last settings passed to setRenderQualitySettings() every time weather changes: the main light (sun/moon direction and color), ambient, procedural sky and clouds, environment tints/intensity, exposure, cloud shadows and the wet/snow material fields are overwritten, while fog density, height fog and volumetric fog/lighting are combined with the user values (the larger density wins). Disabling weather restores the user settings.

Values are clamped by setWeatherSettings() (ranges noted per field). Several effects are driven by timeOfDayHours, so advance it to animate lightning, cloud drift, rain ripples and volumetric fog.
