raisin::RayraiWindow::FoliageRenderDiagnostics ​

struct · #include <rayrai/RayraiWindow.hpp>

Diagnostics: foliage and instanced-draw counters (see foliageRenderDiagnostics()).

Reset at the start of every update() / renderWithExternalCamera() frame and accumulated while that frame renders. Counters prefixed scene belong to the color pass and shadow to shadow passes. GPU times are filled only by captureRenderPassTimings() / captureViewerPassTimings().
