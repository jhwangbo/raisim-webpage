VisualCategory ​

#include <rayrai/VisualCategory.hpp>

cpp
enum class VisualCategory

Render-category flag for user-created visuals and point clouds.

VisualCategory is render metadata. Rayrai uses it when a render policy asks for only capture/detection-visible helper geometry, for example external camera renders, capture paths that reuse external-camera rendering, detectable-only point-cloud rendering, and picking or shadow candidate passes that explicitly require detectable visualization objects.

This flag does not create a physics body, collision shape, dynamics object, or semantic label, and it does not hide an object from the normal interactive viewer. User-created Visuals, InstancedVisuals, PointCloud, and helpers built on top of Visuals default to NotDetectable so debug overlays, camera frustums, axes, labels, and other viewer-only aids do not contaminate external-camera or generated capture images.

Set a visual to Detectable when it should be included in those capture/detection render passes. RaiSim world objects are not controlled by this enum; they follow their own wrapper visibility and the active render pass policy. The RaiSim RGB/depth sensor-camera overloads intentionally disable custom visualization objects and point clouds regardless of this flag.

EnumeratorValueDescription
NotDetectable0Viewer-only by default; excluded from detectable-only render passes.
Detectable1Included when a rayrai render policy asks for detectable custom visuals.

Process-wide query: is the current rayrai installation running in multi-threaded mode (one RayraiWindow per worker thread)?

#include <rayrai/helper.hpp>

cpp
std::optional<glm::vec4> parseColorLiteral(std::string_view input)

Parse a numeric color literal such as "{1.0, 0.5, 0.0, 1.0}" or "1 0.5 0 1".

{, }, (, ), , and whitespace act as separators; parsing stops at any other non-numeric text. The first three numbers are taken as RGB; the optional fourth is the alpha (defaults to 1.0). If the largest RGB channel is in (1, 255], RGB (and an alpha above 1) are interpreted as 0..255 and rescaled. RGB is then clamped to [0, 1]; a non-negative alpha is clamped to [0, 1], while a negative alpha is kept as is.

Returns The parsed color, or std::nullopt if the input cannot be parsed.
