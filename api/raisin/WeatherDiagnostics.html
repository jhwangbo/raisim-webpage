raisin::WeatherDiagnostics ​

struct · #include <rayrai/Weather.hpp>

Resolved weather state for the current frame (RayraiWindow::weatherDiagnostics()).

Echoes the WeatherSettings inputs and reports the values the renderer derives from them. Strengths are normalized [0, 1] unless noted.
