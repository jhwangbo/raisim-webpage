raisin::RenderQualitySettings ​

struct · #include <rayrai/RenderQuality.hpp>

Explicit runtime quality settings for viewer rendering.

The struct stores its fields as a flat layout for historical reasons; the flat fields are the source of truth. For authoring, new code may use the grouped sub-config accessors — shadows(), bloom(), depthOfField(), fog(), toneMapping(), temporalAa() — and the matching set*() writers, which copy to and from the flat fields.

Use RenderQualitySettings::preset(RenderQualityPreset) to start from a known-good configuration, then apply with RayraiWindow::setRenderQualitySettings(). That call clamps many fields to the ranges noted on them and throws std::invalid_argument for invalid temporal-AA parameters; the remaining noted ranges are applied when the value is uploaded to the shaders.

Nested classes ​

  • struct BloomSettings — Bloom / glow controls.
  • struct DepthOfFieldSettings — Depth-of-field controls.
  • struct FogSettings — Distance / height / volumetric fog controls.
  • struct ShadowsSettings — Main directional shadow and cascade controls (additional-light shadow fields are not included).
  • struct TemporalAaSettings — Temporal antialiasing controls.
  • struct ToneMappingSettings — Tone-mapping + color-grade controls.

static RenderQualitySettings preset(RenderQualityPreset p)

Build a RenderQualitySettings for the given preset.

Companion to the existing RenderQualityPreset enum so the type that names the presets can also produce them. Delegates to RayraiWindow::defaultRenderQualitySettings() (defined in RenderQualityDefaults.cpp). The result is not clamped until it is passed to RayraiWindow::setRenderQualitySettings().
