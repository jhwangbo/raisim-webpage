raisin::Material ​

class · #include <rayrai/Material.hpp>

A general-purpose material class supporting PBR, textured, and simple color models.

Plain data: every field is public and read when the material is drawn. usesPbrShading() decides the shader: a material whose type is SIMPLE_COLOR or TEXTURED and whose other fields keep their defaults is drawn by the cheaper simple mesh shader, while Type::PBR (the default) or any PBR-only feature selects the PBR shader; forceSimpleShading overrides both. Texture fields hold OpenGL texture ids that the material does not own (0 = unused). Colors are linear RGB(A) in [0, 1] unless noted.

Nested classes ​

  • struct AlphaSettings — Grouped alpha-handling configuration.
  • struct FoliageSettings — Grouped foliage wind/weather authoring fields.
  • struct ParallaxSettings — Grouped tangent-space heightmap / parallax controls.
  • struct TextureBindingInfo — One row of textureBindingTable(): how applyTo() binds a material texture.
  • struct TextureSlotInfo — Static per-slot metadata for the TextureSlot enum.
  • struct UvTransform — Per-texture UV transform (glTF KHR_texture_transform style).
  • struct VertexDisplacementSettings — Grouped height-map vertex-displacement controls.

receivesActiveWeather ​

cpp
bool receivesActiveWeather() const

True when this material actually picks up weather (wetness/snow).

Mirrors the per-material weather gate in the full PBR fragment shader: a non-PBR or non-porous material, or one that opts out of both wetness and snow, receives no weather effect — so it does not require the weather-capable full shader even when weather is globally enabled. Used by the scene-level shader selection so a per-material weather opt-out actually preserves the core/foliage-fast path (it previously did not).

Returns True when any pass in the chain receives weather.

glass static ​

cpp
static Material glass(
    std::string name="Glass",
    float thickness=0.0f,
    const glm::vec3 &tint=glm::vec3(1.0f),
    float attenuationDistance=1.0f,
    float roughness=0.04f,
    float indexOfRefraction=1.5f)

Dielectric glass. Zero thickness represents a thin window; positive thickness is an authored world-space optical path length for a solid. Tint is the transmitted color after attenuationDistance world units. Keep alpha at one: transmission, not coverage, makes glass transparent. Enable RenderQualitySettings::screenSpaceRefraction for scene transmission. Sets transmissionFactor = 1 and metallic = 0; a thin pane (thickness <= 0) is also made double-sided.

Parameters

ParameterDescription
nameMaterial name.
thicknessOptical path length in world units (clamped to >= 0).
tintTransmitted color, clamped to [0, 1].
attenuationDistanceDistance at which tint is reached (min 1e-4).
roughnessSurface roughness.
indexOfRefractionIOR, clamped to [1, 3].

Returns The configured material.
