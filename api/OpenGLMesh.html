OpenGLMesh ​

class · #include <rayrai/OpenGLMesh.hpp>

Inherits: std::enable_shared_from_this< OpenGLMesh >

Simple OpenGL mesh with indexed geometry and optional textures.

Keeps a CPU copy of the geometry plus a context-local VAO and (possibly shared) VBO/EBO. Constructors and every update/draw method require a current OpenGL context, except createCpuGeometry() and prepareGeometryAttributes(). Texture ids referenced by textures and material are not owned. Meshes are usually held by std::shared_ptr and may be shared between objects (see RayraiGlobalAsset), so material edits on a shared mesh affect every user. Non-copyable and non-movable.

Nested classes ​

  • struct GeometryDiagnostics — Aggregated triangle statistics (see accumulateGeometryDiagnostics()).
  • struct MeshDiagnostics — Internal: per-mesh geometry/material record for structured diagnostics output (see collectMeshDiagnostics()).
  • struct PreparedAttributes — What prepareGeometryAttributes() derives besides the vertex attributes.
  • struct StagedGeometry — Where staging buffers (persistently mapped, OpenGL 4.4) hold this mesh's vertices and indices as uploadPreparedGeometry() stores them.
  • struct VertexSummaries — What precomputeVertexSummaries() and contentDigest() find.

void draw(const Shader &shader) const

Draw the mesh using the provided shader.

Same as draw(shader, RenderMode::All). The shader is not bound here and must already be in use; the model matrix and objectColor are the caller's responsibility. Material depth/stencil/blend/cull state is applied around the draw call.

Parameters

ParameterDescription
shaderShader with expected texture uniforms.
cpp
void draw(
    const Shader &shader,
    RenderMode mode,
    const raisin::Material *materialOverride=nullptr) const

Draw the mesh if it matches the requested material render mode.

Non-PBR modes set the simple-shader material uniforms and bind the diffuse, specular and normal maps to units 0, 1 and 2 (white fallback when absent). PBR modes apply the full material (Material::applyTo()) and also draw its next-pass chain. The shader must already be in use.

Parameters

ParameterDescription
shaderShader with expected material uniforms.
modeMaterial filter for multi-pass rendering.
materialOverrideOptional material to use instead of the mesh material (the mesh's textures are then ignored).

instancedVaoForBuffer ​

cpp
unsigned int instancedVaoForBuffer(unsigned int instanceBuffer) const

Return a VAO whose base mesh attributes plus instance attributes use instanceBuffer.

The instance buffer holds one 80-byte record per instance: a column-major mat4 model matrix (attributes 3-6) followed by a vec4 color (attribute 7). VAOs are created on first use and cached per buffer; call releaseInstancedVaoForBuffer() before deleting the buffer.

createIndexedRangeView static ​

cpp
static std::shared_ptr<OpenGLMesh> createIndexedRangeView(
    std::shared_ptr<const OpenGLMesh> owner,
    const std::vector<Vertex> &localVertices,
    const std::vector<unsigned int> &localIndices,
    size_t firstIndex,
    int baseVertex,
    const raisin::Material &viewMaterial,
    const glm::vec4 &viewBaseColor,
    const std::string &debugName={})

Create a CPU-metadata view into owner's indexed GPU buffers.

The returned mesh has its own material/CPU geometry metadata but shares owner's VAO/EBO/VBO and draws the requested index range. It does not own or delete the shared GL handles, and holds a shared_ptr to owner so the borrowed GL handles cannot dangle.

Taking the owner as an explicit std::shared_ptr makes shared ownership a compile-time requirement (no shared_from_this/bad_weak_ptr fallback that could silently return a non-owning view), and the view is built without any throwaway GL upload — it never allocates its own VAO/VBO/EBO. Returns null if owner is null.

Parameters

ParameterDescription
ownerMesh whose GPU buffers are borrowed.
localVerticesCPU vertices for this view (bounds/diagnostics only).
localIndicesCPU indices for this view; their count is the draw count.
firstIndexOffset, in indices, into owner's index buffer.
baseVertexValue added to each index when drawing.
viewMaterialMaterial of the view.
viewBaseColorBase color of the view.
debugNameDiagnostics name; empty inherits owner's.

Returns The view, or nullptr.

Create a context-local mesh wrapper that reuses another mesh's GPU buffers.

Buffer objects and textures are shared by OpenGL context share groups, while vertex array objects are context-local. This factory copies the CPU/material metadata, retains the shared VBO/EBO allocation, and creates a VAO in the caller's current context.
