#########################################
Server Example: Synchronous Server Update
#########################################

Overview
========
Runs the RaisimServer in a manual socket loop. This shows how to drive
synchronous TCP visualization updates. RaiSim does not support sensor
measurement updates from the visualizer.

Binary
======
CMake target and executable name: ``synchronous_server_update``.

Run
====
Build and run from your build directory:

.. code-block:: bash

   cmake --build . --target synchronous_server_update
   ./synchronous_server_update

On Windows, run ``synchronous_server_update.exe`` instead.
This example uses RaisimServer. Start the rayrai TCP viewer and connect to port 8080. RaisimUnity and RaisimUnreal are no longer supported.


Details
=======
- Runs RaisimServer in synchronous request/response mode.
- Manually accepts a TCP connection and processes world-state update requests.
- ``needsSensorUpdate()`` always returns false because RaiSim does not request
  RGB/depth sensor frames from TCP visualizers.
